# Data directories

This directory intentionally contains no downloaded data in git.

- `raw/`: source records fetched from Hugging Face datasets.
- `processed/`: cleaned, deduplicated, deterministic train/validation JSONL shards.
- `tokenized/`: tokenizer files and memory-mappable integer token shards.

Use the commands in the repository README to populate these directories. Dataset
licenses and revisions are recorded in `manifest.json` files generated by the
preparation scripts.
